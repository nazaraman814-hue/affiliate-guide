◆まず「紹介バック」の仕組みを理解する

全部で3タイプしかない。これを分かれば全案件に応用できる。

タイプA｜友達紹介コード

アプリ内に自分専用のコードがある。友達がそれを入れて登録＋条件クリアで、自分と相手の両方にポイント。PayPay・楽天銀行・UQなど。
審査なし・今日すぐ始められる。

タイプB｜専用URL発行

公式フォームで「紹介専用の申込URL」を発行し、それ経由で契約してもらう。通常ページから申し込まれると0円になるのが最大の罠。LINEMO・楽天モバイル。

タイプC｜ASPアフィリエイト

ASP(広告代理サイト)に登録して広告リンクを貼る。友達じゃなく不特定多数に配れる＝青天井。仮想通貨・証券はここが本命。単価2,000〜10,000円。

結論：タイプA・Bで身内から確実に取りつつ、タイプC(ASP)を仕込んで青天井を狙う ―― これが正しい進め方。 タイプCだけは「登録審査」があるので、今日のうちに申請だけ出しておくのが最速ルート。

◆やる順番（この通りにやれば無駄がない）

理由：後の案件ほど前の案件を「材料」に使うため。順番を逆にすると取りこぼす。

1PayPayアプリ｜紹介 300円 × 人数

難易度：★☆☆☆☆ ／ 一番カンタン。今日中に完了できる。常設キャンペーンなので締切なし。

A. 自分がまだPayPay未登録の場合（先に得する）

  1. 誰かの紹介コードをもらってから登録する。自分から登録すると300円もらい損ねる。友人に「PayPayの紹介コードちょうだい」と聞くだけ。
  2. App Store / Google Play で「PayPay」をインストール。
  3. 電話番号とパスワードを設定 → SMSで届く認証コードを入力。
  4. 登録画面の途中にある「紹介コードをお持ちの方」をタップし、もらったコードを入力。
    ※登録完了後には入力できない。ここが唯一のチャンス。
  5. 銀行口座またはセブン銀行ATMからチャージする（最低1,000円以上）。
  6. コンビニなどで1,000円以上を1回で決済する。
    → 500円を2回に分けるのはNG。1回で1,000円以上が条件。
  7. 数日〜翌月に自分と紹介者の双方に300円分のPayPayポイントが入る。

B. 自分の紹介コードを取り出して配る（ここが収入源）

  1. PayPayアプリを開く。
  2. 画面右下の「アカウント」をタップ。
  3. メニュー内の「あげる・もらう」または「友だち紹介」を選ぶ。
  4. 自分の紹介コード（英数字）と紹介用URLが表示される。「リンクをコピー」または「シェア」をタップ。
  5. LINE・X(旧Twitter)・Instagramのプロフィール等に貼って配布する。
  6. 相手が「登録 → コード入力 → 1,000円以上決済」を完了した時点で、自分に300円分が入る。
相手にはこう伝えると成功率が上がる：
「このコード入れて登録して、コンビニで1,000円以上1回で払ってみて。そっちにも300円分入るから実質タダになるよ」
→ 相手にもメリットがあることを必ず先に言う。これが紹介系で一番大事なコツ。
注意：相手が12〜18歳の場合は特典が500ポイントに増額される期間限定キャンペーンあり(2026/3/3〜終了日未定)。学生に紹介するとお得。

▼ まず自分がPayPayを使う側の手順（これが一番簡単）

  1. アプリストアから「PayPay」をダウンロード。
  2. 電話番号・メールアドレスで登録。本人確認は後でOK（紹介コードを使うだけなら不要）。
  3. 誰かの紹介コードをもらって入力して登録する（自分が未登録なら、知人のコードで入っておくこと。後からコードを入れられない）。
  4. ホーム画面右上の「アカウント」→「友だち紹介」に進む。
  5. 自分の紹介コードが表示されるのでコピーする。
  6. 相手に送る。「PayPayのコード入れて！1回1,000円以上の決済したらお互いに300円もらえる」と伝える。
重要：紹介報酬の条件是「1,000円以上を1回で決済」。分割払いでもOKだが、500円×2回ではダメ。コンビニ・公共料金・ATM入金は対象外。

C. PayPayクレジット（PayPayカード）紹介 500円 × 最大10人 = 5,000円

  1. PayPayアプリ内の「PayPayカード」／「PayPayクレジット」メニューを開く。
  2. 「友だちを誘う」から紹介コード／URLを取得。
  3. 相手が紹介コード経由で新規入会し、期間内に1回決済する。
  4. 双方に500ポイント。自分は最大10人＝5,000ポイントまで。
期間限定：この枠は開催期間が区切られている（直近は2026/6/19〜7/31で実施）。アプリ内で現在開催中かを必ず確認すること。開催していない時期もある。

LINEMO 紹介｜手順（最優先。上限なしで6,000円/人）

  1. LINEMO公式サイトの「紹介キャンペーン」ページを開く。
  2. 紹介専用フォームに自分の名前・電話番号などを入力して送信。
  3. 自分専用の「紹介専用申込URL」が発行される。これをコピーして保管。
  4. 紹介したい相手にそのURLを送る。
  5. 相手がそのURLからLINEMOに申し込み、翌月末までに開通させる。
  6. 開通日の7ヶ月後の上旬に、自分へ6,000円分のPayPayポイントが付与される。
絶対に外してはいけない3点
① 相手が通常の申込ページから契約すると特典は0円。必ず発行したURLから申し込ませる。
② ソフトバンク・ワイモバイル・LINEモバイルからの乗り換えは対象外。docomo/au/楽天/他格安SIMからならOK。
③ ポイント付与前に相手が解約すると、自分の分も無効になる。
自分がLINEMOを先に契約しておく必要がある理由：紹介キャンペーンでURLを発行するには「LINEMO契約者」であること。
手順：① LINEMO公式サイトから申し込む → ② 本人確認（郵送で届いたSIMの番号入力） → ③ 開通 → ④ 紹介キャンペーンページからURL発行
報酬が入るまで7ヶ月かかるのがこの案件の唯一の弱点。逆に言えば7ヶ月後に確実に入るので、今から仕込むほど早く回収が始まる。

楽天モバイル｜自分が契約する時は「三木谷キャンペーン」を使う

これは紹介バックではなく自分がもらう分。だが金額が大きいので必ず経由すること。

  1. 通常の楽天モバイル公式サイトからは申し込まない。
  2. 三木谷キャンペーン専用リンク（キャンペーンコード 2798）経由でアクセスする。
  3. Rakuten最強プランを選択（データ通信専用プランは対象外）。
  4. 他社から電話番号そのまま乗り換え(MNP)なら14,000pt、新規契約なら11,000pt。
  5. 開通・利用開始 → 条件達成の翌々月末頃から3ヶ月に分けて自動付与。
1人1回線まで。また予告なく終了する可能性があるキャンペーンなので、契約予定があるなら早めに。

楽天モバイル｜他人を紹介して7,000pt もらう

  1. 楽天モバイル契約者になる（上記で自分が契約済みならOK）。
  2. my楽天モバイル アプリ／サイトの「紹介キャンペーン」から紹介URLを取得。
  3. 相手にURLを送り、そこから申し込んでもらう。
  4. 相手が開通・利用 → 自分に7,000ポイント。
合わせ技：相手には「三木谷キャンペーンのリンク」を教えれば相手は14,000pt、自分は紹介で7,000pt ―― 両取りが可能。相手にも最大メリットが出るので断られにくい。

3銀行口座｜紹介 1,000円 × 最大10人

難易度：★★☆☆☆ ／ 相手に「5万円入金」というハードルがあるため、身内向き。

楽天銀行｜口座紹介プログラム（自分 1,000pt／相手 最大7,200pt）

▼ まず自分が楽天銀行の口座を作る（これが最初の一歩）

  1. 楽天銀行の公式サイトにアクセス。
  2. 口座開設申込ボタンを押す。
  3. 必要事項を入力（氏名・住所・生年月日・電話番号・勤め先など）。
  4. 本人確認書類をスマホで撮影（運転免許証／マイナンバーカード／健康保険証のいずれか）。
  5. 審査通過（通常翌営業日）→ 楽天銀行IDとパスワードがメールで届く。
  6. ログイン → マイページ → 「口座紹介キャンペーン」ページで自分の紹介コードを取得。
ポイント：口座を作った時点で「自分の分」のセルフバック(1,000pt)は出ないが、相手側が5万円入金する条件を満たせば相手は最大7,200ptもらえる。相手のほうが得なので勧誘しやすい。

▼ 自分が紹介する側の手順

  1. 楽天銀行にログイン → マイページ内の「口座紹介キャンペーン」ページを開く。
  2. 自分の紹介コード（例：P45864204 のような英数字）が表示されるのでコピー。
  3. 相手に「口座紹介キャンペーン特設ページ」のURLと紹介コードの2つをセットで送る。
  4. 相手が特設ページから口座開設を申し込む。
  5. 相手が申込フォーム内の紹介コード入力欄にコードを入力する。
  6. 相手が口座開設完了後、ATM入金または他行振込で、一度に5万円以上を入金する。
  7. 自分に1名につき1,000ポイント（最大10名＝10,000ポイント）。
最大の落とし穴：紹介コードは口座開設の申込フォームの中でしか入力できない。開設完了後に「やっぱりコード入れたい」は不可能。 相手には「申込の途中で必ずこのコードをコピペして」と、コードと一緒に強調して伝えること。
また、特設ページ以外から開設されると双方の特典が激減する。必ず特設ページのリンクを送る。
相手側のメリット（説得材料）：紹介コード入力で200pt ＋ 5万円入金で3,000pt ＋ 楽天グループのサービスを1つ利用で合計5,200pt／2つ利用で合計7,200pt。 さらに「はじめてのご利用プログラム」で現金最大2,000円も別途もらえる。相手のほうが得な設計なので勧めやすい。
相手に必須の前提：楽天会員であること、「楽天ハッピープログラム」にエントリーしていること。この2つを先に案内するとスムーズ。

auじぶん銀行｜紹介 1,000円（現金）× 最大10人

自分がauじぶん銀行の口座を作る手順：auじぶん銀行アプリまたは公式サイトから「新規口座開設」 → 氏名・住所・生年月日・勤め先を入力 → 本人確認書類（運転免許証等）を撮影送信 → 審査通過（通常翌営業日） → 口座開設完了
  1. auじぶん銀行アプリ／サイトの「ご家族・ご友人紹介キャンペーン」ページを開く。
  2. 紹介コードまたは紹介URLを取得して相手に送る。
  3. 相手が口座開設 → 所定の条件を達成。
  4. 自分に1名につき現金1,000円（最大10名＝10,000円）、相手に現金2,000円。
ポイントではなく「現金」で入るのがこの案件の強み。ポイント有効期限を気にしなくていい。開催期間が区切られているので公式で実施中か確認すること。

三菱UFJ銀行｜口座紹介プラン

  1. 三菱UFJ銀行アプリまたはWebの「口座紹介プラン」ページへ。
  2. 紹介リンク／紹介コードを取得して相手に共有。
  3. 相手が紹介リンク経由で口座開設。
  4. 合計2名以上紹介すると特典（抽選応募口数など）。紹介人数が多いほど当選確率が上がる方式。
確定報酬ではなく抽選型。期待値は楽天銀行やauじぶん銀行より低い。他をやり切ってから着手すればよい。

4仮想通貨アカウント｜2,000〜5,000円 × 人数 ＋ 継続報酬

難易度：★★★☆☆ ／ 国内はASP経由の固定報酬、海外は取引手数料の継続シェア。

STEP 0｜まずASP（アクセストレード）に登録する（これが一番大事）

  1. www.accesstrade.ne.jp にアクセスし「無料会員登録」。
  2. メールアドレス登録 → 届いたメールのURLから本登録へ。
  3. 氏名・住所・電話番号・報酬振込先の銀行口座を入力（先に作った楽天銀行などを使う）。
  4. 掲載メディアを登録。SNS（Instagram/X/YouTube）のアカウントURLでOK。ブログ不要。
  5. 審査を待つ（数日）。承認されたらログイン → 「プログラム検索」から「仮想通貨」「金融」ジャンルを選ぶ。
  6. 案件に「提携申請」（承認まで数日）。
  7. 承認された案件の広告リンクを取得。
このASP経由で取る理由：① 取引所直結の友達紹介だと0円の場合が多い ② ASP経由なら「本人確認完了」で2,000〜5,000円の現金 ③ 「アフィバックモール」を使えば自分の口座開設分でも報酬が出る（SBI証券は公式0円→セルフバックで約9,000円）。まずはこれに登録する。

STEP 1｜まず自分が口座を開設する（説明できないと紹介できない）

  1. 取引所を選ぶ。初心者に勧めやすいのは Coincheck（アプリが分かりやすい）か bitFlyer（国内最大手）。
  2. メールアドレスとパスワードでアカウント登録。
  3. SMS認証（携帯番号）を通す。
  4. 本人確認：スマホで運転免許証／マイナンバーカードを撮影＋自分の顔を撮影（eKYC）。ここが必須で、紹介報酬の成果条件もほぼ「本人確認完了」。
  5. 審査完了まで最短即日〜1営業日。完了メールが来たら口座開設完了。
  6. 銀行口座（先に作った楽天銀行など）を登録して入金できる状態にする。
先に自分がやる意味：①相手に手順を説明できる ②ASPの「セルフバック」を使えば自分の開設分でも報酬が出る案件がある。ASP登録が先に済んでいれば二度おいしい。

◆やってはいけないこと（報酬没収・アカBANの原因）

1. 自分で複数アカウントを作って自分を紹介する（自己紹介・不正利用）
最も多い没収理由。家族名義でも同一世帯・同一端末・同一IPは検知される。報酬没収に加えアカウント停止もある。
2. 「絶対儲かる」「必ず値上がりする」などの誇張表現
仮想通貨・金融案件では明確に禁止。成果が発生していても広告主に否認され報酬0円になる。金商法・景表法にも抵触しうる。
3. 広告であることを隠す（ステマ）
2023年10月からステマは景品表示法違反。SNSやブログに広告リンクを貼るときは「PR」「広告」「アフィリエイト広告を含みます」の明記が義務。
4. 通常ページから申し込ませてしまう
LINEMO・楽天銀行で頻発する事故。専用URL／特設ページ以外からの申込は報酬0円。相手に送るときは「必ずこのリンクから」と一言添える。
5. 確定申告を忘れる
紹介報酬・アフィリエイト収入は雑所得。給与所得者は年間20万円超で申告義務が発生する。ポイントで受け取った分も原則課税対象。
